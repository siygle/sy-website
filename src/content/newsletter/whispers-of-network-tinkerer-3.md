## Shopify 猛猛的

![](https://twitter.com/Shopify/status/1464228247625998382)

Shopify 一直在電子商務上表現得很不錯，如果有關注他們應該也知道他們也算硬底子的公司，經常可以看到技術相關的分享，這次的 BF 當然也不例外，有興趣也可以看一下他們的火力展示（原來是 GCP 的大客戶，Google 應該也很開心 😁）

![](https://twitter.com/ShopifyEng/status/1465806691543531525)

## JetBrains 再闢新戰場

![](https://twitter.com/JetBrains_Fleet/status/1465224866706112515)

以 IDE 聞名的 [JetBrains](https://www.jetbrains.com/) 最近發出這個新聞 - [Next-generation IDE](https://blog.jetbrains.com/blog/2021/11/29/welcome-to-fleet/)（夠狂，不過這個領域大家都很愛用這個形容詞😆），除了特別強調 lightweight editor 之外，也連帶宣佈了遠端開發的服務，這擺明是把 Github (微軟) 當成假想敵嘛 😎

## Vercel 開始默默地收集 rust 成員

看來不是錯覺喔，從[上篇](https://chat.sylee.dev/2021/11/28/%e7%b6%b2%e8%b7%af%e9%bb%91%e6%89%8b%e7%9a%84%e5%91%a2%e5%96%83-2/)提到的 swc 開始，又默默加了 [rust 核心開發成員](https://twitter.com/ag_dubs)進來（雖然曾經都是 Node.js 圈子裡的人啦），看來真的是打算把工具鏈用 rust 重寫過的樣子喔。
